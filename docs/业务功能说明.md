# 业务功能说明

> 项目名称：基于 Claude Skill 的竞品动态追踪与智能对标分析系统
> 文档版本：v1.0 ｜ 对应课件第一天上午

---

## 一、业务总体概述

当前企业传统竞品分析高度依赖人工检索、整理与复盘，存在**情报零散、更新滞后、对标口径不统一、人力成本高、难以支撑实时战略决策**等问题。

本系统以 Anthropic Claude 大模型为智能内核，结合 **LangChain 框架、Multi-Agent 多智能体协作与 RAG 检索增强技术**，聚焦**价格战、新品发布、负面舆情**三大核心监控维度，实现竞品情报**采集 → 清洗 → 结构化解析 → 横向对标 → 时序分析 → 风险预警 → 智能报告生成**的全链路自动化。

系统采用**插件化 Agent 架构、统一注册表管理、RAG 时序知识库设计**，支持业务模块热插拔扩展，可长期沉淀竞品数据，为产品迭代、定价策略、市场运营及风险防控提供标准化、可落地的智能决策支撑。

---

## 二、核心业务设计思路

系统遵循 **「数据采集 → 智能解析 → 多维对标 → 风险研判 → 报告输出 → 持续迭代」** 的闭环业务流程：

1. **多源自动采集**：聚合官网、行业媒体、社交平台、电商等公开舆情数据，定时抓取竞品动态；
2. **AI 结构化解析**：依托 Claude Skill 工具调用与 Prompt 工程，从海量非结构化文本中精准提取价格、产品、舆情类有效情报；
3. **多智能体并行分析**：通过价格、新品、舆情三类专属 Agent 分工处理，实现细分维度专业化对标；
4. **时序深度对比**：基于 RAG 向量库沉淀历史数据，支持长周期纵向趋势分析与多竞品横向对标；
5. **风险与机会研判**：智能识别竞品市场动作，分级输出风险预警与潜在业务机会；
6. **标准化智能简报**：自动生成日报、周报、月报及专项分析报告，输出可直接用于汇报的结论与优化建议。

## 三、核心业务功能模块

### 模块一：竞品与数据源配置管理
为系统分析业务提供基础规则支撑，支持用户自主定义监控体系。主要功能包括：
- 竞品档案新增、编辑与状态管理，可设置监控优先级；
- 针对价格、新品、舆情三大维度，自定义监控关键词与触发规则；
- 配置多源舆情数据源，支持自定义抓取频率与优先级。

> 对应代码：`modules/llm_client.py`（配置加载）、`.env` / `.env.example`

### 模块二：多源舆情自动采集与清洗
替代人工整理工作，实现竞品数据高效、高质量入库：
- 支持定时轮询与手动增量采集，仅更新新增动态，避免重复计算；
- 依托 Claude 语义能力自动过滤广告、软文、无效信息，完成舆情降噪；
- 通过文本分块预处理保障语义完整性，输出标准化结构化数据，存入业务库与向量库，形成时序数据资产。

> 对应代码：`modules/data_loader.py`（WebLoader / RSSLoader / DataLoader 增量去重）

### 模块三：插件化多 Agent 智能对标分析
系统采用标准化插件化架构，通过抽象基类统一约束插件接口，以唯一抽象属性 `name` 作为插件标识，结合注册表实现统一管理，支持模块热插拔扩展。内置三类核心分析智能体：

| Agent | 职责 | 输出 |
|-------|------|------|
| **价格监控智能体** | 抓取竞品定价套餐、阶梯价格、优惠补贴、促销活动，横向对标识别价差优势与降价风险 | 价格波动与时序趋势结论 |
| **新品迭代智能体** | 监测竞品版本更新、功能增减、服务升级，梳理功能差异与迭代缺口 | 产品优化参考建议 |
| **负面舆情智能体** | 抓取用户投诉、差评、媒体负面报道，判别舆情等级与核心问题 | 竞品口碑短板与我方竞争机会 |

此外包含**时序对比分析**：依托 RAG 向量库历史数据，自动生成价格、产品、舆情变化趋势，结合多竞品横向对比，研判竞品短期动作与长期战略布局。

> 对应代码：`modules/agent_core.py`（AbstractAgent / AgentRegistry / PriceAgent / ProductAgent / SentimentAgent / AgentOrchestrator）、`modules/tools.py`

### 模块四：分级风险预警研判
- 支持自定义预警触发规则，针对竞品降价、大规模补贴、核心功能上线、集中负面舆情等关键动作监控；
- 设置**三级预警机制**：紧急 / 常规 / 长期战略风险；
- 由 Claude 自动解读事件影响、研判竞品意图，通过定时汇总与实时提醒推送预警结果。

> 对应代码：`modules/agent_core.py`（alerts 字段）、`modules/api_server.py`（/api/analyze）

### 模块五：智能竞争态势简报生成
整合多 Agent 分析结果与时序数据，自动生成标准化竞品分析报告：
- 涵盖动态汇总、多维对标、趋势分析、机会威胁研判、落地优化建议；
- 内置多套报告模板，支持数据图表可视化展示；
- 可导出 PDF / Word / Markdown 格式，支持日 / 周 / 月定时自动生成。

> 对应代码：`modules/prompts.py`（REPORT_TEMPLATE）、`modules/api_server.py`（/api/report）

### 模块六：插件扩展与知识库管理
提供系统底层能力支撑：
- 支持 Agent 插件热插拔扩展，新增分析维度无需改动核心代码；
- 通过 RAG 向量库持久化沉淀舆情数据、分析记录、行业资料，支撑语义检索与时序复盘；
- 全流程记录运行日志，结合 LangSmith 实现推理链路追踪与性能优化。

> 对应代码：`modules/rag_chain.py`、`modules/agent_core.py`（AgentRegistry）

### 模块七：服务化接口与可视化看板
- 基于 FastAPI 将智能分析链路封装为标准 RESTful API，支持异步流式输出；
- 前端提供可视化情报看板，集中展示竞品动态、对标图表、预警消息与报告预览；
- 支持多角色权限管控，满足团队协同配置、分析、查看、导出等分工需求。

> 对应代码：`modules/api_server.py`

## 四、核心业务价值

1. **效率革新**：大幅提升调研与分析效率，替代重复性人工工作；
2. **精准提升**：依托 AI 语义理解与 RAG 检索，减少人工遗漏与主观偏差；
3. **决策支撑**：不止罗列数据，输出可落地的产品、定价、运营优化建议；
4. **持续扩展**：插件化架构可持续扩展分析能力，知识库长期沉淀企业竞争资产；
5. **风险前置**：实现竞品风险前置预判，从事后复盘转向事前预警、事中快速应对。
